# DisBots - Tienda Online

Proyecto Final DAW 2025/2026

## Descripción

DisBots es una tienda online desarrollada para la venta de bots de Discord.

## Tecnologías utilizadas

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* JQuery
* AJAX
* Git y GitHub

## Funcionalidades

* Registro de usuarios
* Inicio de sesión
* Roles de administrador y usuario
* Gestión de productos
* Carrito de compra
* Subida de imágenes
* Filtros y paginación
* Exportación PDF
* Diseño responsive

## Instalación

1. Importar la base de datos.
2. Configurar la conexión en config/db.php.
3. Iniciar Apache y MySQL.
4. Abrir el proyecto en el navegador.
